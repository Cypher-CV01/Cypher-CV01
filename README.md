### Linguagens de Programação

- **Java 21/23**: Experiência com as versões mais recentes do Java, aplicando boas práticas e padrões modernos de desenvolvimento.
- **Python 3**: Domínio de Python para automação, desenvolvimento de scripts e construção de APIs.

### Frameworks e Bibliotecas

- **Spring Boot**: Framework para construção de microserviços e aplicações Java escaláveis e leves.
- **Spring Data**: Integração com bases de dados relacionais, simplificando o acesso a dados em aplicações Java.
- **Spring MVC**: Desenvolvimento de aplicações web com o padrão Model-View-Controller.

### Desenvolvimento de APIs

- **API REST**: Criação de APIs escaláveis, seguindo as melhores práticas de design RESTful.
- **RabbitMQ**: Implementação de sistemas de mensageria assíncrona para comunicação entre microserviços.
- **Kafka**: Plataforma para construção de pipelines de dados em tempo real e comunicação entre componentes de sistemas distribuídos.

### Bancos de Dados

- **PostgreSQL**: Banco de dados relacional utilizado para garantir integridade e performance em consultas complexas.
- **MySQL**: Banco de dados relacional amplamente usado para aplicações web, conhecido por sua simplicidade e alta performance.
- **MongoDB**: Banco de dados NoSQL, ideal para lidar com grandes volumes de dados não estruturados.

### Ferramentas e Tecnologias

- **Docker**: Containerização de aplicações para garantir consistência e portabilidade entre diferentes ambientes.
- **Git**: Controle de versão para gestão de código-fonte e colaboração em equipe.
- **Maven**: Automação de builds e gerenciamento de dependências em projetos Java.

### Sistemas Operacionais

- **Linux**: Desenvolvimento e administração de sistemas em ambientes Unix/Linux.
- **Windows Server**: Administração de servidores e ambientes corporativos baseados em Windows.

### Redes e Comunicação

- **TCP/IP**: Sólido conhecimento sobre os protocolos de comunicação fundamentais para redes, incluindo **TCP**, **UDP**, e endereçamento **IPv4/IPv6**.
- **Sub-redes**: Experiência em criar e gerenciar sub-redes, incluindo o uso de mascaramento de rede e roteamento eficiente.
- **DNS e DHCP**: Configuração e resolução de nomes de domínio (DNS) e alocação automática de endereços IP (DHCP).
- **Monitoramento de Redes**: Utilização de ferramentas como **Wireshark** e **Tcpdump** para análise e diagnóstico de pacotes de rede.

### Automação e Scripts

- **Shell**: Automação de tarefas e gerenciamento de sistemas com scripts em Bash.
